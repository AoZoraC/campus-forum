# 校园汇 · campus-forum

一个面向学校的**学习交流与资源分享论坛**。同学可以按板块发帖、讨论课程问题、分享课件与复习资料。

> ✅ **项目状态：功能已完成，准备部署（阶段 6 / 7）**
>
> 登录、发帖、回帖、搜索、点赞、附件上传下载全部可用。剩下最后一步：部署到公网。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| **邮箱登录** | 注册、登录、退出、邮箱验证、忘记密码 / 重置密码 |
| **论坛核心** | 按板块发帖、回帖（支持楼中楼）、板块筛选 |
| **资源分享** | 发帖时上传附件、下载计数、作者可删除自己的附件 |
| **搜索** | 同时搜索帖子标题与正文，中文友好 |
| **点赞收藏** | 同一个人对同一条帖子只能赞一次（数据库唯一约束保证） |
| **权限分级** | 普通用户 / 管理员；作者或管理员可删帖 |
| **移动端适配** | 手机上板块导航变成可横滑的胶囊条，发帖入口常驻 |

## 技术栈

| 用途 | 选型 |
| --- | --- |
| 框架 | Next.js 16（App Router + Turbopack + Cache Components） |
| 界面 | React 19 + Tailwind CSS 4 |
| 语言 | TypeScript |
| 数据库 | PostgreSQL（Supabase）+ Prisma 7 |
| 文件存储 | Supabase Storage（生产）/ 本地硬盘（开发），自动切换 |
| 密码 | bcrypt 哈希（cost 12） |
| 会话 | 数据库会话 + httpOnly cookie |

## 本地运行

```bash
npm install          # 安装依赖（会自动跑 prisma generate）
npm run dev          # 启动开发服务器
# 浏览器打开 http://localhost:3000
```

需要先在项目根目录创建 `.env`（参考 `.env.example`），至少填数据库地址：

```ini
DATABASE_URL="postgresql://..."   # 连接池地址，端口 6543
DIRECT_URL="postgresql://..."     # 直连地址，端口 5432
```

配置好后：

```bash
node scripts/check-env.mjs       # 自检地址填得对不对（不连数据库，只看格式）
npx prisma migrate deploy        # 把表结构应用到数据库
npx prisma db seed               # 写入初始板块
```

## 项目结构

```
app/            页面。文件夹路径 = 网址路径
  api/download/ 文件下载接口（统计下载次数）
  post/[id]/    帖子详情（动态路由）
components/     可复用组件
  auth/         登录注册相关的表单
lib/
  actions/      写操作（发帖、点赞…）。带 "use server"，浏览器可调用
  queries.ts    读操作（查帖子、查板块…）。普通模块
  storage/      存储层：本地/云端双实现，按环境变量切换
  db.ts         数据库连接（单例）
  session.ts    会话管理
prisma/         数据库结构定义与迁移历史
scripts/        运维小工具（自检、查看数据库状态等）
docs/           项目文档（部署指南、踩坑记录等）
storage/        本地开发时上传的文件（不入库）
```

**一条重要的划分**：`lib/actions/*` 是**写操作**（浏览器可调用的入口），`lib/queries.ts` 是**读操作**（内部实现）。搞混会导致难以排查的报错。
