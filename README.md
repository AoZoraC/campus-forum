# 校园汇 · campus-forum

一个面向学校的**学习交流与资源分享论坛**。同学可以按板块发帖、讨论课程问题、分享课件与复习资料。

> 🚧 **项目状态：开发中（阶段 1 / 7）**
>
> 首页骨架已完成，页面上的内容目前**全部是假数据**。数据库、登录、发帖等功能正在逐步实现。

## 技术栈

| 用途 | 选型 |
| --- | --- |
| 框架 | Next.js 16（App Router + Turbopack） |
| 界面 | React 19 + Tailwind CSS 4 |
| 语言 | TypeScript |
| 数据库 | PostgreSQL + Prisma（阶段 2 接入） |
| 用户登录 | 邮箱 + 密码（阶段 3 接入） |

## 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器打开
# http://localhost:3000
```

改动 `app/page.tsx` 并保存后，浏览器会自动刷新。

## 项目结构

```
app/          页面。文件夹路径就是网址路径，app/page.tsx 就是首页 /
components/   可复用组件（顶栏、板块导航、帖子列表）
lib/          数据与工具函数（目前是假数据）
public/       静态资源（图片等）
```
